# Animo

Programma di animazione e compositing (stile After Effects) per Windows.

## Scaricare

Vai in **[Releases](https://github.com/Gesprosio/animo-releases/releases/latest)** e scarica **Animo-Setup-x.y.z.exe**.
Una volta installato, Animo si aggiorna da solo.

Alla prima installazione Windows potrebbe mostrare un avviso (SmartScreen): "Ulteriori informazioni" › "Esegui comunque".

Questo repository contiene solo il programma compilato e gli aggiornamenti, non il codice sorgente.
