# Animo

Programma di animazione e compositing (stile After Effects) per Windows.

## Scaricare

Vai in **[Releases](https://github.com/Gesprosio/animo-releases/releases/latest)** e scarica:

- **Animo Setup x.y.z.exe** — versione da installare (consigliata): si aggiorna da sola.
- **Animo Portable x.y.z.exe** — versione portable, senza installazione (non si aggiorna da sola).

Alla prima installazione Windows potrebbe mostrare un avviso (SmartScreen): "Ulteriori informazioni" › "Esegui comunque".

Questo repository contiene solo i programmi compilati e gli aggiornamenti, non il codice sorgente.
